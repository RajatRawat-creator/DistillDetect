# Data

All datasets ship in this repo — no external download. The pre-computed
reference-MIA **result** JSONs are not here; they live in `../ReferenceMIAResults/`
with the CPU-only reproduction scripts.

## Folders

| Folder             | Contents                                                                | Consumer                               |
|--------------------|-------------------------------------------------------------------------|----------------------------------------|
| `training/`        | Teacher response JSONLs for student SFT                                  | `training/`                            |
| `MIADatasets/`     | Controlled candidate-teacher responses (4 teachers × OMI/s1, 200 rows)  | `reference_mia/run_controlled.py`      |
| `wild/`            | Wild-model candidate responses (10-teacher pool; +Qwen-3-235B for X-Coder) | `reference_mia/run_wild.py`         |
| `omi_cot_fewshot/` | Per-student few-shot candidate responses (OMI-CoT students)             | `reference_mia/run_omi_cot.py`         |
| `o1/`              | o1 ASCII-vs-Unicode paired JSONLs                                        | `o1_detection/run_o1_ascii_unicode.py` |

## `training/` provenance

Each `Teacher=<T>_Data=<D>_Template=<TPL>.jsonl` is the verbatim teacher output
from `generation/generate_local_vllm.py`, for teachers
**Nvidia-Llama-3.3-70B-Instruct**, **GPT-OSS-120B**, and **Qwen-3-8B** over the
OMI and s1 prompt sets (plus the Llama OMI-CoT template variant).

## `wild/` provenance

Candidate-teacher responses for the **wild** reference MIA — a 10-way
classification over: **Claude Opus 4.5, Claude Opus 4.6, Claude 3.5 Sonnet,
DeepSeek R1, GPT-OSS-120B, Gemma-3-27B-it, Llama-3.3-70B-Instruct,
QwQ-32B-Preview, o1, o3**. **Qwen-3-235B** is included only for the X-Coder
11-way pool (activated via `_files_map_xcoder.json`).

**22 jsonl files total** (each teacher × OMI/s1, 200 rows), uniformly named
`<model>_omi(200).jsonl` / `<model>_s1(200).jsonl`. All files share the same 200
OMI and 200 s1 questions, and each row is
`{teacher_model, prompt_id, input_source, prompt_format, question, response}`
(QwQ uses `output`). Closed-API outputs (Claude, OpenAI) were produced via vendor
APIs.

> **Truncation.** The reference-MIA runners score only the first 2,048 answer
> tokens (`--max_answer_tokens 2048`), so long reasoning traces contribute only
> their leading 2,048 tokens to the reference-normalized loss.

## `MIADatasets/` provenance

Controlled candidate-teacher responses (4 teachers × OMI/s1, 200 rows each),
consumed by `reference_mia/run_controlled.py`.

> **Format-marker stripping.** For two teachers we strip the format scaffolding
> so detection can't lean on an obvious stylistic giveaway (making the task
> harder / more realistic): the **Qwen-3-8B** files
> (`Qwen3-8B__…__vllm_cleaned.jsonl`) have the `<think>…</think>` tags removed,
> and the **GPT-OSS-120B** files (`gpt-oss-120b__…__vllmCLEAN.jsonl`) have the
> harmony `assistantfinal` / channel markers removed.

## `omi_cot_fewshot/` provenance

Candidate datasets for the **OMI-CoT students** — the four base models
(Qwen-2.5-1.5B, Qwen-2.5-3B, Llama-3.2-3B-Instruct, Gemma-3-4B-PT) distilled on
the Llama OMI(918) OMI-CoT data. One subfolder per student, each holding the four
candidate teachers' responses generated with that student's own last-15 boxed
outputs as in-context few-shot exemplars (200 rows each); all 16 files are
student-specific. This is the "+ In-context exemplars from S" (`Reference_Fewshot`)
condition, generated by `generation/generate_teacher_vllm_fewshot.py`.

## `o1/` provenance

Two JSONLs that differ only in non-ASCII encoding (`\uXXXX`-escaped vs raw
UTF-8), used by `o1_detection/` to detect o1-distillation.
